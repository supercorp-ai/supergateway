# Getting help

- **Questions, setups, "how do I…":** ask on [Discord](https://discord.gg/CudcAH53yF). It's the fastest way to get an answer.
- **Something doesn't work as documented:** [open a bug report](https://github.com/supercorp-ai/supergateway/issues/new?template=bug_report.yml). Run with `--logLevel debug` and include the output.
- **An idea or a missing feature:** [open a feature request](https://github.com/supercorp-ai/supergateway/issues/new?template=feature_request.yml).
- **A security issue:** don't open an issue; follow [SECURITY.md](SECURITY.md).

Before opening an issue, try the latest version (`npx -y supergateway@latest`) and search [existing issues](https://github.com/supercorp-ai/supergateway/issues?q=is%3Aissue).
