# Security policy

## Supported versions

Security fixes go into the latest 4.x release. Please upgrade to the newest version (`npx -y supergateway@latest`) before reporting.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub instead: [Report a vulnerability](https://github.com/supercorp-ai/supergateway/security/advisories/new) (Security tab → Report a vulnerability).

Include the version, the command or config you ran, and what an attacker could do. We'll reply within a few days, fix it, and credit you in the release notes unless you'd rather not be named.
